# E2E Foundation and Current-App Suite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an end-to-end test setup that drives the real DevUtility app (XCUITest), plus Jest unit tests, and cover every current feature with passing tests, run locally by `npm run test:all` and in GitHub Actions.

**Architecture:** A new `E2E` Xcode build configuration (copy of Release, separate bundle ID `org.reactjs.native.DevUtility.e2e`, compile flag `E2E_BUILD`) builds the app the tests launch. A UI test target `DevUtilityE2ETests` holds support helpers, page objects (one per panel area) and spec files. Product code gains `testID`s, a status-item accessibility identifier and an E2E-only `--e2e-reset` launch flag. Jest covers pure logic.

**Tech Stack:** XCUITest (Xcode 26), Swift 5, React Native for macOS 0.76, Jest 29, `xcodeproj` Ruby gem (ships with CocoaPods) for project edits, GitHub Actions `macos-26`.

**Spec:** `docs/superpowers/specs/2026-10-21-multi-tool-panels-and-e2e-design.md` (delivery step 2; read "Testing" and the spike results under "Delivery order").

## Global Constraints

- Work on branch `test/e2e-foundation`, created from `docs/multi-tool-design`. Never commit to `main`.
- Commits: Conventional Commits, `type(scope): summary`, lowercase, imperative, no period, under ~72 chars. End every commit message with:
  ```
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_01KGsmAssYfT2eNfN8BxeCyy
  ```
- Production bundle ID `org.reactjs.native.DevUtility` must not change. E2E bundle ID is exactly `org.reactjs.native.DevUtility.e2e`.
- Accessibility identifiers follow `<area>.<element>[.<index>][.<part>]`, all lowercase camelCase segments (`clipboard.row.0.copy`). Only page objects contain identifier strings; spec files never do.
- Tests wait for conditions (`waitForExistence`, `Wait.until`), never `sleep`. Default wait 5s; launch wait 20s.
- `--e2e-reset` has effect only in builds compiled with `E2E_BUILD` (the `E2E` configuration).
- Current-app behavior is described as it is today. If a test reveals behavior that contradicts the spec's description of today's app, stop and report it; do not change the test to match, do not skip it.
- Code standards from `CLAUDE.md`: descriptive names, no comments that restate code, no change-log file headers on new files, no debug prints, no dead code.
- `npm run test:all` must pass before any task is reported complete; paste the summary line of each layer.

## Review Focus

1. Clipboard text with emoji, non-Latin scripts and multiple lines must appear and re-copy byte-for-byte (test in Task 6).
2. Very large clipboard text (100,000 characters) must be captured without hanging and shown truncated in the row (test in Task 6).
3. Whitespace-only clipboard content: today it is captured as an entry because `'   '` is truthy; the test pins this current behavior (Task 6).
4. Search text containing regex-special characters (`c++`, `a.b`, `(x)`) must match literally (test in Task 7).
5. Corrupt JSON in storage must load as an empty list, not crash (Jest test in Task 4).

`scripts/xcode/add-e2e-targets.rb` (idempotent: safe to run twice):

```ruby
# Adds the E2E build configuration and the DevUtilityE2ETests UI test target.
# Run from the repo root: ruby scripts/xcode/add-e2e-targets.rb, then: npm run pods
require 'xcodeproj'

PROJECT_PATH = File.expand_path('../../macos/DevUtility.xcodeproj', __dir__)
APP_TARGET_NAME = 'DevUtility-macOS'
TEST_TARGET_NAME = 'DevUtilityE2ETests'
E2E_CONFIGURATION = 'E2E'
E2E_BUNDLE_ID = 'org.reactjs.native.DevUtility.e2e'

project = Xcodeproj::Project.open(PROJECT_PATH)
app_target = project.targets.find { |target| target.name == APP_TARGET_NAME }

def add_configuration_copied_from_release(configuration_list, project)
  return if configuration_list[E2E_CONFIGURATION]

  release = configuration_list['Release']
  e2e = project.new(Xcodeproj::Project::Object::XCBuildConfiguration)
  e2e.name = E2E_CONFIGURATION
  e2e.build_settings = Marshal.load(Marshal.dump(release.build_settings))
  e2e.base_configuration_reference = release.base_configuration_reference
  configuration_list.build_configurations << e2e
end

add_configuration_copied_from_release(project.build_configuration_list, project)
project.targets.each do |target|
  add_configuration_copied_from_release(target.build_configuration_list, project)
end

app_e2e = app_target.build_configuration_list[E2E_CONFIGURATION].build_settings
app_e2e['PRODUCT_BUNDLE_IDENTIFIER'] = E2E_BUNDLE_ID
app_e2e['GCC_PREPROCESSOR_DEFINITIONS'] = ['$(inherited)', 'E2E_BUILD=1']
app_e2e['SWIFT_ACTIVE_COMPILATION_CONDITIONS'] = '$(inherited) E2E_BUILD'

unless project.targets.any? { |target| target.name == TEST_TARGET_NAME }
  test_target = project.new_target(:ui_test_bundle, TEST_TARGET_NAME, :osx, '11.0')
  test_target.add_dependency(app_target)
  add_configuration_copied_from_release(test_target.build_configuration_list, project)
  project.main_group.find_subpath(TEST_TARGET_NAME, true).set_path(TEST_TARGET_NAME)
end

test_target = project.targets.find { |target| target.name == TEST_TARGET_NAME }
test_target.build_configurations.each do |configuration|
  settings = configuration.build_settings
  settings['PRODUCT_NAME'] = '$(TARGET_NAME)'
  settings['TEST_TARGET_NAME'] = APP_TARGET_NAME
  settings['GENERATE_INFOPLIST_FILE'] = 'YES'
  settings['PRODUCT_BUNDLE_IDENTIFIER'] = 'org.reactjs.native.DevUtilityE2ETests'
  settings['SWIFT_VERSION'] = '5.0'
  settings['CODE_SIGN_IDENTITY'] = '-'
  settings['CODE_SIGN_STYLE'] = 'Manual'
  settings['MACOSX_DEPLOYMENT_TARGET'] = '14.0'
end

test_group = project.main_group[TEST_TARGET_NAME]
existing_paths = test_target.source_build_phase.files_references.map(&:real_path).map(&:to_s)
Dir[File.join(File.dirname(PROJECT_PATH), TEST_TARGET_NAME, '**', '*.swift')].sort.each do |path|
  next if existing_paths.include?(path)

  relative_dir = File.dirname(path).sub(File.join(File.dirname(PROJECT_PATH), TEST_TARGET_NAME), '').delete_prefix('/')
  group = relative_dir.empty? ? test_group : test_group.find_subpath(relative_dir, true)
  group.set_path(File.basename(relative_dir)) unless relative_dir.empty? || group.path
  test_target.add_file_references([group.new_reference(File.basename(path))])
end

project.save

scheme_path = File.join(PROJECT_PATH, 'xcshareddata', 'xcschemes', "#{APP_TARGET_NAME}.xcscheme")
scheme = Xcodeproj::XCScheme.new(scheme_path)
unless scheme.test_action.testables.any? { |testable| testable.buildable_references.any? { |ref| ref.target_name == TEST_TARGET_NAME } }
  scheme.test_action.add_testable(Xcodeproj::XCScheme::TestAction::TestableReference.new(test_target))
end
scheme.save!
```

Why: hand-editing `project.pbxproj` is error-prone; the script makes the change reviewable and repeatable (rerun it after adding new test files). `MACOSX_DEPLOYMENT_TARGET` 14.0 for the test bundle avoids the `XCUIAutomation built for 14.0` linker warning the spike saw.

```swift
import XCTest

enum Wait {
  static let defaultTimeout: TimeInterval = 5

  static func until(
    _ description: String,
    timeout: TimeInterval = defaultTimeout,
    file: StaticString = #filePath,
    line: UInt = #line,
    condition: @escaping () -> Bool
  ) {
    let predicate = NSPredicate { _, _ in condition() }
    let expectation = XCTNSPredicateExpectation(predicate: predicate, object: nil)
    let result = XCTWaiter().wait(for: [expectation], timeout: timeout)
    XCTAssertEqual(result, .completed, "Timed out waiting until \(description)", file: file, line: line)
  }
}
```

`scripts/run-e2e-tests.sh`:

```bash
#!/bin/bash
# Builds the E2E configuration and runs the XCUITest suite against it.
set -euo pipefail

PROJECT_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
RESULTS_DIR="$PROJECT_ROOT/build/e2e"
RESULT_BUNDLE="$RESULTS_DIR/DevUtilityE2E-$(date +%Y%m%d-%H%M%S).xcresult"
INSTALLED_APP_ID="org.reactjs.native.DevUtility"

# The installed DevUtility registers the same global shortcut as the test build;
# while it runs, the test build's shortcut registration fails and hotkey tests break.
installed_app_was_running=$(osascript -e "application id \"$INSTALLED_APP_ID\" is running" 2>/dev/null || echo false)
if [[ "$installed_app_was_running" == "true" ]]; then
  echo "==> Quitting installed DevUtility for the test run (it is reopened afterwards)"
  osascript -e "quit app id \"$INSTALLED_APP_ID\""
fi
reopen_installed_app() {
  if [[ "$installed_app_was_running" == "true" ]]; then
    open -b "$INSTALLED_APP_ID" || true
  fi
}
trap reopen_installed_app EXIT

mkdir -p "$RESULTS_DIR"
xcodebuild test \
  -workspace "$PROJECT_ROOT/macos/DevUtility.xcworkspace" \
  -scheme DevUtility-macOS \
  -configuration E2E \
  -derivedDataPath "$PROJECT_ROOT/build/e2e-derived-data" \
  -resultBundlePath "$RESULT_BUNDLE" \
  -only-testing:DevUtilityE2ETests \
  NODE_BINARY="$(command -v node)" \
  "$@"

echo "Results: $RESULT_BUNDLE"
```

```swift
import XCTest

enum AppLauncher {
  static let launchTimeout: TimeInterval = 20

  static func launchFresh() -> XCUIApplication {
    Pasteboard.clear()
    let app = XCUIApplication()
    app.launchArguments = ["--e2e-reset"]
    app.launch()
    waitUntilReady(app)
    return app
  }

  static func relaunchKeepingData(_ app: XCUIApplication) -> XCUIApplication {
    app.terminate()
    app.launchArguments = []
    app.launch()
    waitUntilReady(app)
    return app
  }

  private static func waitUntilReady(_ app: XCUIApplication) {
    let clipboardTab = app.descendants(matching: .any)["header.tab.clipboard"]
    XCTAssertTrue(
      clipboardTab.waitForExistence(timeout: launchTimeout),
      "DevUtility did not finish launching"
    )
  }
}
```

`src/testSupport/StorageResetGate.tsx`:

```tsx
import React, {useEffect, useState} from 'react';
import AsyncStorage from '@react-native-async-storage/async-storage';

interface Props {
  shouldReset: boolean;
  children: React.ReactNode;
}

export function StorageResetGate({shouldReset, children}: Props) {
  const [isReady, setIsReady] = useState(!shouldReset);

  useEffect(() => {
    if (!shouldReset) {
      return;
    }
    AsyncStorage.clear()
      .catch(error => console.error('E2E storage reset failed', error))
      .finally(() => setIsReady(true));
  }, [shouldReset]);

  return isReady ? <>{children}</> : null;
}
```
