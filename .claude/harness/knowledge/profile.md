## The developer

These apps are my personal projects, built end to end with Claude ("vibe coding", but held to
production quality). Why I build them:

- **Build useful things**: applications that help me in my day-to-day life.
- **Learn AI tools**: get hands-on with Claude Code and other AI tooling, and learn how to build
  AI-powered tools and features myself.
- **Keep the craft**: the code should look like it was written by a careful senior engineer, so
  I (or anyone) can pick up any project months later and understand it quickly.

I run several projects in parallel, each in its own Claude session. Assume the reader of the
code is a developer with 2-3 years of experience who has never seen this project.

When you make a non-obvious choice (library, pattern, architecture), say briefly why in your
reply; I want to learn from the work, not just receive it.
